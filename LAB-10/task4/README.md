# Task 4: Simple HTML Page Renderer

## Project Description
This Express.js application demonstrates how to render a complete HTML page with title, paragraph, and a list from the root route.

## Requirements Met ✓
- ✅ Uses Node.js + Express
- ✅ No database
- ✅ No Postman required
- ✅ Output shown in browser
- ✅ Root (/) route returns full HTML page
- ✅ Includes title
- ✅ Includes paragraph
- ✅ Includes simple list

## Installation

1. Navigate to task4 folder:
```bash
cd LAB-10/task4
```

2. Install dependencies:
```bash
npm install
```

## Running the Server

Start the server:
```bash
npm start
```

The server will start on `http://localhost:3002`

## Testing the Route

Open your browser and visit:

- **Home:** `http://localhost:3002/` - Shows complete HTML page with title, paragraph, and list

## Page Contents

The HTML page includes:

1. **Title:** "Welcome to Our Page"
2. **Paragraph:** Descriptive text about the page and Express.js
3. **List:** Features list including:
   - Simple and Clean Design
   - Responsive Layout
   - Beautiful Gradient Background
   - Smooth Hover Effects
   - Server-Side HTML Rendering
   - Easy to Customize
   - Works on All Browsers
   - Cross-Platform Compatible

## Features

- ✨ Full HTML page rendering

## Stopping the Server

Press `Ctrl + C` in the terminal to stop the server.
